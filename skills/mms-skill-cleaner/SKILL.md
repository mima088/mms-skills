# 米妈 Skill 发布前审查

在把 skill 分享出去前，扫描目标 skill 的 SKILL.md 和 references/，找出不该外流的内容。

## 检查清单

| 等级 | 检查项 | 说明 |
|---|---|---|
| 🔴 | 知识库原文 / 案例素材 | references 里是否有课程逐字稿、案例库原文、范文库全文 |
| 🔴 | 本地路径 | IMA、桌面、`~/.codex`、绝对路径等只有本人机器能用的路径 |
| 🔴 | 价格 / 微信 / 手机号 | 399、1980、微信号、电话等 |
| 🔴 | 真实姓名 / 可识别学员信息 | 学员姓名、孩子真名、可定位的家庭信息 |
| 🟡 | 销售话术 / 硬广 | 成交话术、课程种草、引导加微信等（若刻意保留会员引导，标为“有意保留”） |
| 🟡 | 内部字样 | “公开版”“内部版”“仅限本人”“给小北使用”等 |

## 输出格式

```
📋 Skill 发布前审查报告

检查对象：[skill 名 / 路径]

🔴 必须删除
- [位置] [内容摘要] → 建议：[怎么改]

🟡 需确认
- [位置] [内容摘要] → 是“有意保留”还是“应删除”？

🟢 可以发布
- [简述哪些内容没问题]

结论：可发布 / 需修改后再发布
```

## 原则
1. 只报告，不擅自改；用户说“改”才改。
2. 宁可多标一条，不漏标一条。
3. 会员引导（如 mimayuerji.cn、社群入口）如果是刻意保留的转化点，标 🟡 让用户确认，不要当垃圾删掉。

## 完成后
按 `mms` 总入口的「技能联动路由表」，主动给出 1 个最相关的下一步建议（最多 1 个，不刷屏）。
