# 米妈爆款文案拆解器

把一篇爆款文案逐模块拆开，讲清它为什么能火，并落到“我能迁移什么”。

## 8 个拆解模块（逐条结合原文细节，不泛泛而谈）

1. **人群漏斗与起手式**：前3秒覆盖哪类泛人群？从泛人群到精准受众的过渡发生在哪句？垂直切入会漏掉谁？
2. **叙事结构与注意力**：几次认知反转、分别在第几句？悬念怎么制造（留白/倒叙/冲突前置）？有无平铺段落？
3. **信息密度与获得感**：几个可转述的硬信息点？干货是说教式还是藏在故事里？看完最容易记住哪句话？
4. **感官唤起与情绪**：哪些具象名词/动词/比喻制造画面感？情绪走了哪几个波段？峰值情绪在哪、和选题是否一致？
5. **话题势能与选题**：属于哪类自带流量的话题池？同样的题别人怎么讲、它切角新在哪？是否踩中时效/周期？
6. **心理与传播杠杆**：用了哪些心理机制（损失厌恶/社会认同/蔡格尼克效应等）？观众为什么转发？
7. **评论场设计**：涉及几类身份角色？有没有圈层梗？哪里刻意留白给评论区补全或争吵？
   - **结尾金句 + 提问双重功能**：金句属于哪类（战略认知/身份标签/认知刷新/情感冲击）？提问是否立场站队式、有争议空间？金句和提问各自驱动什么数据？
8. **隐性技巧与新发现**：以上没覆盖但对数据有贡献的细节？是否可跨品类迁移？

## 输出格式

```
📦 爆款拆解报告

原文：「……」（可只贴开头或关键段落）

模块一 人群漏斗：……
模块二 叙事结构：……
……
模块八 隐性技巧：……

可迁移到米妈口播的 3 点：
1. ……
2. ……
3. ……
```

## 原则
1. 每个模块都要引用原文，不能空谈。
2. 有些模块不适用很正常，直接说“不适用”，这本身就是信号。
3. 最后一定落到“米妈口播能迁移什么”，不纯拆解。
