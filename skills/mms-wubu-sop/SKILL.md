# 米妈深度内容五步 SOP

把深度内容从“非标品”变成“标品”：不靠灵感，也能稳定产出高质量、能日更、可持续的内容。

## 核心洞察
传统自媒体认为“质量、高频、持续”三者不可兼得，是因为两个隐含前提：
1. 高质量必须耗费大量时间；
2. 输出只能消耗自己已有的知识储备。
推翻这两个前提，三者就能兼得。

## 五步 SOP（产出一篇深度内容）

1. **锚定普遍现象**：问 AI“大众在这个选题上的普遍表现/常见场景”，用强画面感快速圈定人群。
2. **戳中普遍误解**：挖出大众对这个现象最普遍的错误认知，制造危机感和好奇。
3. **深挖误解根源**：从个体心理/成长环境、社会文化两个层面拆解“为什么会误解”。
4. **输出正确认知**：给一个清晰的正向判断和认知升级方向，让观众获得启发感。
5. **提供落地攻略**：给一个完整可执行的大致流程框架，激发行动意愿，但不透露付费产品核心细节。

## 两个辅助原则

- **随意输出**：不追求精致场景、完美状态、完整脚本；通勤、等位、登机都能拍。真实工作场景下的表达比摆拍更有“活人感”，适合专家型 IP。
- **输出即输入**：每次和 AI 围绕选题深度碰撞，都会反向扩充你自己的知识体系。内容产出越多，个人储备反而越丰富，从根源上解决创作枯竭。

## 输出格式

```
🎯 选题：……

第1步 锚定普遍现象：……
第2步 戳中普遍误解：……
第3步 深挖误解根源：……
第4步 输出正确认知：……
第5步 提供落地攻略：……

一句话钩子：……
```

## 原则
1. 五步都要能直接用于口播，口语化，不说教。
2. 第5步只给框架，不透支付费产品的核心交付。
3. 全程“活人感 + 情绪翻译 + 别指责家长”。
