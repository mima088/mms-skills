# 米妈账号定位与人设

定位是做决策，不是套模板。一次只定一条主线。

## 定位公式
账号定位 = 价值 × 用户（内核） + 人设（灵魂） + 类型 × 风格（形式）

- 内核：价值 × 用户 —— 你提供什么价值、解决谁什么问题
- 人设：你以为的你是谁，不决定你做什么账号；能力可迁移（大厂产品经理→教职场规划；不婚女性→教独立）
- 形式：类型 × 风格

## 找竞争优势：正 / 反 / 合 三招

### 正：交叉优势、立体竞争
- 兴趣爱好 + 普世价值：甲骨文+爱情、围棋+人生、美食+文化
- 特殊领域 + 普世价值：律师+父女生活、中医+治愈生活
- 常规类型 + 私人生命体验：情侣+旅行、美食+女儿成长
- 价值叠加：普世且陌生（大众+小众），醉翁之意不在酒
- 句式：美食的关键不在于食物，而在于……；旅行的关键不在于景点，而在于……

### 反：否定对抗、找准敌人
- 谁是敌人（未满足的人群、沉默市场）→ 找准敌人快速理解市场
- 对标的作用：干掉他 or 对着干
- 只有否定才能更好地肯定；只有排除敌人才能构建共同体
- IP = 影响力 = 政治；IP 是鲜明立场的代言人

### 合：交 —— 理性壁垒 + 情感羁绊
- 立体竞争：既有品味又有流量，不博眼球、不抄袭

## 人设与商业
- 在商言商：想清楚怎样的人设利于做生意；商家背书人设最重要
- 不要逼着消费者爱上你才买你的东西；对别人是缺点、对消费者是优点
- 三种变现姿态：配得上他 / 极其低姿态 / 极其高姿态

## 输出格式

```
🎯 账号定位方案

一句话定位：……
内核：价值 × 用户 ——……
人设：……
形式：类型 × 风格 ——……
竞争优势：正（交叉优势）…… / 反（敌人）…… / 合（壁垒+羁绊）……
变现姿态：……
```

## 原则
1. 先定主线再动手，一次只走一条路。
2. 从最优势出发，不凭空造人设。
3. 定位要能落到“可发布内容”上，不写虚词。
