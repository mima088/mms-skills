# 米妈口播共鸣诊断

检查文案能不能让观众觉得“这说的就是我”。

## 四个维度
1. 具象细节：有没有具体时间/地点/动作/孩子原话，还是通篇抽象道理？
2. 情绪波段：观众会经历哪几种情绪？是不是只有“讲道理”一种？
3. 对号入座：观众能不能自然说出“这就是我”？钩子是不是太窄？
4. 立场站队：有没有让观众站到某个被理解的立场，而不是被教育？

## 输出
```
📋 共鸣诊断报告
1. 具象细节：✅/❌（引用原文）
2. 情绪波段：……→……→……
3. 对号入座：够广 / 太窄
4. 立场：被理解 / 被教育

结论 + 2 处具体改法（可直接念出来）
```
