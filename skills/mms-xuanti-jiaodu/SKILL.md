# 米妈选题角度生成器

同一个主题，换 14 个角度，就是 14 个选题。解决“讲完了、没灵感”。

## 14 个选题角度

1. 多维度解决问题 —— 跨学科交叉给全景解法
2. 意想不到的学科角度 —— 用A领域工具解释B领域（用“沉没成本”讲感情拖延）
3. 前沿方法重审经典 —— 用新方法/新技术重做老课题
4. 挖掘盲点与忽视 —— 找大众没注意的“缝隙”
5. 聚焦常识中的矛盾点 —— 在“理所当然”里抓认知失调
6. 逆向思维 —— 反常识质疑 + 失败案例 + 反向对照组
7. 极端假设 —— 极限情境 / 边缘文化 / 极端环境
8. 时间维度 —— 故事发展脉络 / 历史与代际演变
9. 特殊境遇 —— 地域特殊 / 虚拟空间 / 微观场景
10. 小题大作 —— 从一件小事折射宏大议题
11. 深度分析 —— 对比 / 类比迁移
12. 个人化视角 —— 第一人称贴近式叙事
13. 多主体视角 —— 多方角色立场与互动
14. 叙事腔调包装 —— 借用知名节目/文学体裁的风格

## 万能起手 prompt
「这是我对选题角度的理解，我是卖{{ }}的，给我从这些角度分别给我选题」

## 输出格式

```
🎯 主题：……

按角度出选题（每个角度 1-2 个，可直接用的口播方向）：
1 多维度：……
2 意想不到：……
……（挑相关性高的角度，不必硬凑14个）
```

## 原则
1. 角度服务于“真实经历 + 活人感”，不生搬硬套。
2. 优先给能勾起好奇、覆盖广的角度。
3. 出的选题要能落到具体故事，不写空标题。
