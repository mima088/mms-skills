# 米妈口播逐字稿体检

从两个层面检查口播逐字稿，最后给改法。

## A 层：完播层（刺点 + 骨架 + 势能）

### 五类情绪刺点（按要撬动的行为分）
- 点赞刺点：高潮反转 / 金句 / 卧槽感
- 评论刺点：提问引导 / 埋梗 / 站队 / 说一半留一半
- 收藏刺点：实用 / 以后用得上 / 信息过载
- 传播刺点（转发@）：社交货币 / 记忆扳机 /「快转给你家队友」
- 关注刺点：人设背书 / 人格魅力 / 价值栏目

检查线：
1. 前 200 字刺点 ≥5；
2. 结尾 200 字刺点 ≥6，是否一句一刺激；
3. 五类刺点是否都有覆盖？缺哪类（评论刺点、传播刺点最常被漏）；
4. 全文是否存在“连续 3 行以上无刺激点”的平段；
5. 变调调侃是否明显偏少（全篇绷紧、没有喘息）。

### 骨架推进类型
- 共鸣推进：具象 + 抽象穿插，具象为主、抽象画龙点睛
- 理性逻辑推进：二元对立 / 欲扬先抑 / 三段论 / 不断颠覆
- 节奏推进：卡点 / 排比 / 押韵 / 长短句

检查线：
6. 骨架是哪种推进？是否单一到让观众疲劳、是否需要叠加另一种；
7. 势能：素材是否层层递进？有没有“平行排布、无关信息削弱势能”的平段；
8. 颗粒度：信息点之间有没有粘连、该跳跃的地方有没有大胆跳。

## B 层：顺畅层（衔接/密度/口播）

1. 逻辑衔接：上段结尾 → 下段开头有没有跳（缺过渡）；
2. 信息密度：有没有重复、绕圈、“正确的废话”；
3. 口播流畅：单句过长（>30 字警惕）、书面语、自问自答连续用、术语没解释。

## 输出格式

```
📋 口播逐字稿体检报告

【A 完播层】
- 前200字刺激点：X 个（≥5）✅/❌
- 结尾200字刺激点：X 个（≥6）✅/❌
- 五类刺点覆盖：点赞✅ 收藏✅ 关注✅ 评论❌ 传播❌（缺什么补什么）
- 骨架推进：当前是……，可叠加……
- 势能：有无平段 / 第X段
- 变调调侃：够 / 不足（缺几处）

【B 顺畅层】
🔴 / 🟡 / 🟢 问题清单（引用原文 + 问题 + 改法）

结论：可直接用 / 需修改
```

## 原则
1. 不指责创作者，说“这里可以更顺/更透气”，不说“你写错了”。
2. 改法必须能直接念出来，保持创作者自己的语气。
3. 改法贴“活人感 + 情绪翻译 + 别指责家长”。
4. 如果整体很顺，就说“没什么大问题”，不硬找茬。
