# 米妈逆袭实验文案框架

教技能只是外壳，真正的钩子是“我替你试了，你也行”。把一个干货选题写成一个“普通人逆袭实验”，观众消费的不是教程，是“原来我也可以”的希望感。

## 核心顺序：轻问 → 先出 → 钓素材 → 改

- 不要深度采访一小时，也不要问透再写。
- 正确顺序：一轮快问（3-4 个）→ 立刻出稿 → 用稿子倒逼用户纠偏 → 改。
- 理由：稿子是可攻击的靶子，空问题不是。普通用户说不出“有用”的东西，但你甩一版具体成稿过去，他会马上来劲：“不对，我当时不是这样”。

## 一、采访式起手（让用户倒，一次一问）

普通用户不知道什么有用，所以要顺着时间线和画面往下追，一次只问一个，不要列一堆问题让他填空：

1. 破冰：“来，随便说，想到哪说到哪，不用组织语言。”（先卸下“我要说好”的包袱）
2. 时间线：“你几点开始坐下的？最后弄完是几点？”（过程锚的命）
3. 第一个画面：“你动手干的第一件事是啥？屏幕上第一个蹦出来的是啥？”（具体到能拍）
4. 卡点：“中间有没有哪一步卡住了、不知道咋弄？后来怎么过的？”（翻车→救回，最值钱）
5. 顿悟点：“有没有哪一刻你心里‘卧槽原来这么简单’？”（情绪高点）
6. 够了就打住：“好，素材够了，我现在按框架给你出文案。”

## 二、按锚点补缺（只问缺的）

- **反差锚**：有没有刷到过“别人已经会、我还不会”的现象 / 账号 / 数字？没有就不硬问，用【】占位。
- **身份锚**：问“你自己现在算哪类人？”（宝妈 / 上班族 / 学生 / 副业党……）——问的是“自己”，写出来自动就是“替你这类人试试”。
- **过程锚**：时间戳 + 具体步骤 + 翻车→救回。
- **降门槛锚**：一开始最担心什么？后来怎么解决的？
- **兜底锚**：这技能对你最实在的用处是什么？最好 / 中等 / 最差各是什么？

## 三、素材分工（防素材限制发挥）

- **框架管上限**：五锚点的起承转合、金句写法，skill 自己来，不靠素材。
- **范本管质感**：`references/examples.md` 里的范例是天花板，告诉 skill 好稿长啥样。
- **用户素材只管真实锚点**：时间戳 / 成本 / 翻车 / 顿悟，有 1-2 个真细节，整篇就立住了。
- 一句话：**用户给“事实”，skill 给“手艺”。** 手艺不靠素材，素材再少也不限制发挥。

## 四、真实性边界（守真诚人设 + 开头留人）

把事实分成两类，用不同的标准：

| 类型 | 标准 | 写法 |
|---|---|---|
| 关于“我”的事实（过程/成本/结果/翻车） | 硬真，一丝不掺 | 自己几点开始、花多少钱、做成啥样，全真 |
| 关于“外部现象”的事实（刷到的账号/数据） | 转述 + 模糊 | 说“我刷到过，说是……”“评论区有人讲……”，不说“我查证过” |

三条铁律：
1. 关于自己 → 硬真；
2. 关于外部 → 用“我刷到 / 听说 / 评论区看到”转述，不冒充查证；
3. 数字留余地 → 说“几十万”不说“14万”，说“一下午”不说“3小时15分”。

## 五锚点模型（一个都不能少）

### 1. 反差锚 —— 用反常识数据炸开认知
- 不铺垫，开场直接甩 3 组具象数字/案例
- 一句金句收束（范例：“人类还在担心35岁失业，永生猫已经月入28万了”）
- 底层逻辑：先制造“我亏了”的焦虑——别人已经在赚，我还不会

### 2. 身份锚 —— 把“我”换成“我们”
- 自报小白身份（“我就是那种看10个教程还学不会的人”）
- 替观众出征（“今天我替那些总说‘我不会’的人试试”）
- 底层逻辑：我不是来卖课的，我是跟你一样的小白的代理人，先降低防御

### 3. 过程锚 —— 时间戳制造真实感
- 立 flag：“现在是8:50，挑战开始” → 收束：“现在是10:50，完成了”
- 过程比结果可信：直接说“两小时能学会”没人信，看着他从 8:50 坐到 10:50 就信了
- 拆 3-5 步，每步配一句“我刚才试了，真的成了”，可有“翻车→救回→成功”的小起伏

### 4. 降门槛锚 —— 拆掉所有“但是”
- 主动替观众说出顾虑，一个个拍碎：不会写提示词？说人话就行。电脑小白？网页打开就用。要花钱？今天一分没花。
- 底层逻辑：爆款教程的本质不是教，是消除行动障碍；每多一个“但是”，转化率掉一半

### 5. 兜底锚 —— 三级安全网，做不成也有用
- 最好：火了 → 直接当简历/爆款案例
- 中等：10条里1条有流量 → 投流加码变爆款案例
- 最差：全没流量 → 当作品集，应聘 MCN/市场部/新媒体
- 底层逻辑：把“能不能成”的赌局变成“怎么都不亏”的确定性；人不害怕努力，怕努力了没用

## 通用公式
一个反常识的赚钱/省时现象 + 一个小白替你出征的实验 + 带时间戳的真实过程 + 层层降低的行动门槛 + 哪怕失败也有用的兜底

## 输出格式

```
🎯 选题：……（新技能/新玩法）

一句话定位：不是教XX，是做一场“我替你试了”的实验

1 反差锚：3组数字/案例 + 金句
2 身份锚：小白自报 + 出征宣言 + 立flag（时间戳）
3 过程锚：3-5步，每步一句“试了成了”
4 降门槛锚：观众3个“但是”逐个拍碎
5 兜底锚：最好/中等/最差 三级

收尾金句：……
```

写完稿后，固定补一句：“【】里的素材是占位的，你有真实观察到的信息替换进去就行。”

## 原则
1. 事件的主角不是技能，是“普通人完成了一次自我证明”；技能只是道具。
2. 全程口语化、活人感，说人话不写教程腔。
3. 关于自己的事实硬真、不虚构；外部现象转述模糊、数字留余地；没素材就用【】占位，不替 TA 编。
4. 兜底锚必须落到读者自己的简历/作品集/省时间，不说空话。

## 完成后
按 `mms` 总入口的「技能联动路由表」，主动给出 1 个最相关的下一步建议。
