# 范文对标写稿（通用版）

以爆款范文为活样本，调用你自己的素材库，写出有个人风格的文案。

## 内置范文（references/范文/）

本 skill 自带 11 篇范文 + 风格卡，见 `references/范文/`：
- `风格卡_总表.md`（一眼扫读，快速选范文）
- `范文01~11`（完整范文原文）
- `范文库索引.md`（清单）

## 写稿流程

1. **选范文**：读 `references/范文/风格卡_总表.md` 选一篇，再完整读那篇范文原文，感受它的起头、节奏、口吻。
2. **调弹药**：调用「内容资产管理」整理好的素材库——
   - 内容单元（观点/方法/概念）给专业干货；
   - 人设事实（真实故事）给第一人称经历；
   - 案例（脱敏）给共情。
3. **对标写稿**：照着那篇范文写，**不提炼规则、不套模板**，保留它的活人感。
4. **出稿 + 标题三件套**：封面标题（15字内）、视频上方标题（20字内）、左下角文案（20字内）。

## 关键纪律

- **范文是风格样本，不是内容模板**：范文里出现的事实、故事、人物、经历，都是范文作者自己的。对标写稿时，**只学它的起头、节奏、口吻、结构，不套用其中任何具体事实**，必须换成你自己的真实素材。

- **范文是活样本**：不提炼统一底层逻辑，每篇范文各有特点，对标哪篇就保留哪篇的味道。
- **真实，禁止编造**：涉及你本人/家庭的具体信息，先查你的人设事实库，禁止凭空编造兴趣班、乐器、场景。
- **案例脱敏**：客户/学员案例必须脱敏，去真名、去可识别细节。
- **三类弹药叠加**：观点给「专业」，人设事实给「真实」，案例给「共情」——三者叠加才有个人风格。
