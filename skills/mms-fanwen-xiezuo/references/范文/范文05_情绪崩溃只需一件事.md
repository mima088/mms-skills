# 范文5：情绪崩溃只需一件事

孩子和家长情绪崩溃只需做一件事

开头：遇到孩子情绪崩溃或者我们自己情绪崩溃的时候，只要做一件事情就可以。我在老大一年级的时候崩溃过好多次，怎么？你还会崩溃的？来听我给大家描述一下，你就也没有那么焦虑了。

经过：一年级的时候他们老师在学校也给他们大量读题，回来吗？我就要大量给他读题，对吧？他识字量还没有那么快跟上，但是我就确实不太耐心，就不想读，我就想了个懒招，我说你就用那个词典笔去扫，实在扫了还是不懂的你再来问妈妈。就这句话给我埋下了雷，三十秒钟就听到“妈妈这个什么意思？”一分钟就听到“妈妈这个字我知道怎么读，但我不知道意思。”“妈妈这个题怎么解？”“妈妈我实在是不懂。”我就跟他说这样吧，你把所有不会的你先跳过，就暂时不管他，你把你会的先都写了，不会的最后集中到一起再来找妈妈。妈妈一次性能给你解决。他有点懵的看着我点点头，回去他自己房间了。过了一会又“妈妈这个题怎么办？我不懂，不行，我一定要现在知道。”我说“你集中到最后一起问我，不行吗？”他说“不行，我一定要现在知道，我一定要现在知道这个到底什么意思。”怎么说呢？这孩子有点完美主义，随我是好事也是坏事，我能理解，但是我正在干我的事情，他一直一直打断我，打断我，打断我了一百次，两百次，你们知道那种感觉吗？我就问了自己一个问题，他到底在跟我表达什么？他到底想跟我表达什么？他想跟我表达他的什么需求？他不是故意的，我着急，我焦虑于他怎么没有自主解决问题的能力，他怎么这么依赖我？我厌烦，不耐烦的点在于我教了他方法了，可是他依然没有改观。所以他到底在向我表达他什么样的需求呢？他想把这件事情做好，但是他能力不够，他什么能力不够？独立思考的能力不够，还是识字量不够？哪个问题更优先一些？哪个能力更优先一些？我给他备了很多工具，有词典笔，有AI的工具，有学习机。我认为是独立思考的能力不够，可是独立思考的能力不够又是因为什么？独立思考的意识没有。那怎么样才能让他有独立思考的意识呢？我跟他说“你遇到问题的时候先自己想三个解决办法，这三个办法都尝试了，都解决不了问题再来找妈妈。”他听完之后很懵，懵的就又去做他的作业去了，这个叫我的频率确实降低了一些，没有说五分钟叫八百次了。好孩子遇到不会的又来找我了，他说“妈妈这个，这个我好想知道它到底是什么意思，我解决不了，我好烦。”我说“你想了哪三个办法？”他说“第一个我用了词典笔，我知道那个发音，但是我还是这个意思搞不明白。第二个我翻了课本，我去找课本上有没有就是学过的，但是我没找到。第三个他说妈妈第三个方法我没想出来。”这是他第一次给我反馈的时候，我说“还有AI，你可以去问它。”他说“哦”，我说“那你现在再去试一下，再回来告诉妈妈。”过了五分钟他回来说“妈妈我还是不懂”，我说“咋回事？”他说“AI那个解释我也听不太懂。”我一想好像也有可能，因为孩子现在的这个有些解释它是需要一个人固有的知识点作为基础它才能理解的。孩子现在一年级，他固有的这个知识点就不够，这个基础就不够，所以他有些东西理解不进去是正常的。我说“好的，那你在用这三个方法的过程当中遇到什么问题了吗？”他说“词典笔能帮我就是发音，扫过去我有的时候扫不准，就发现这个读出来好像不对。”我说“对，你得扫准了，还有吗？”他说“不知道了”，因为他刚一年级，有的问题他答不出个所以然来也正常。我说“好的，那来妈妈给你看看这个问题。”其实这个过程它的核心并不是说一定要想出三个办法来，而是通过强制暂停、复盘思考、语言外化的这个过程，让孩子从埋头解题转向抬头看路，看什么路呢？看自己的一个思考路径。这种跳出问题本身审视自己如何思考的过程就是建立元认知的一个过程，长期坚持孩子会养成主动反思自己思考方式的这么一个习惯，这比单纯学会解答某道题更有价值。我不知道这样讲能不能理解，反正也是教育学上的一个规律。那这个方法我原来不知道吗？我原来就知道，但我为什么用不出来？是因为我的情绪也上脑了，情绪上脑了之后我没有理智，我就一直陷在“好难受，打断我，好抓狂，咬牙切齿，不耐烦”这种状态里，直到我开始问自己那个问题，“他真正想要表达的自己的需求到底是什么？”理智再重新回归才走出崩溃，也才能解决他的崩溃。为什么讲这个？大家是不是都听过我们需要看见孩子，但是什么才叫看见孩子呢？你看见他很崩溃，很委屈，很抓狂，很想要急于解决当前的这个问题，是的，你看见了他的情绪，这个就叫看见孩子吗？不是。看见有三个层次，第一个层次叫做看见一个人的行为，比如他哭闹着找我非要马上解决一个问题，这是他当前的行为。第二个层次叫看见一个人的情绪，比如他很着急，他没办法再等一等，他目前没有耐心，这是他的情绪。第三个层次叫做看见一个人的需求，比如说孩子的需求就是他需要培养元认知的能力，这是他的需求。元认知是一个人能不能成为学习高手的关键，不单是学习高手，就他做任何事情他能不能成为一个高手的关键。普通思考是“我在想事”，元认知是“我知道我在想事，我还知道我想的对不对，要不要换一个方式想”，我不知道这样讲能不能理解，就是我们能看到自己的思考路径、思维方式。没有元认知的孩子经常有一些典型的行为表现，比如一根筋，容易死机，遇到困难的时候要么放弃，要么炸毛，一错再错，就同一个坑他会反复的踩，他不擅长从错误里面去学到东西。还有就是依赖别人给答案，而说不出自己到底是怎么想的，思维过程一团乱麻。当我们能看到一个人的情绪的时候，能说出一个人情绪的时候意味着我们的关系会很好，互相之间能够感受到爱，但是解决不了问题。当我们能看到一个人的需求的时候意味着我们可以解决问题了，因为满足了他的需求就能够解决问题。我有一条视频是说家长怎么跟老师配合，在老师面前要人前一套，背后一套的那条视频底下有一个评论是说“一有压力就会和孩子发火，发完火自己又会后悔”，其实就跟我之前的情况差不多，我崩溃了，我也朝孩子发火了，我说“你怎么不能全部都写完了，集中起来在一起问我呢？非要每次都打断我”，声音非常的大，嗷嗷叫。发火没有关系，妈妈们很多时候的发火都源自于自己身体的疲惫，有时候是忍不住的。那你忍不住了发火发就发了吧，但重点是最后我们能不能反思以及真的解决问题，它是一个动态调整的过程，它不是一个“我一发火就罪大恶极，就完全就不是一个合格妈妈”，你不能下这个结论。其实就跟孩子的错误是他每一次进步的方向一样，我们每一次的这种所谓的错误也是我们每一次进步的方向。我以前也经常后悔，但是后来我发现后悔是一种特别低的能量，与其后悔那我们不如好好反思，反思是一种特别稀有又高能量的能力，只要我们反思并改变那我们就是非常棒的妈妈，大家同意吗？反正我作为一名家庭教育咨询师我就是不想传递太过于焦虑的这种情绪，因为妈妈们太难了，太难了，谁人无过呢？有的时候也不要把我们自己看得太重，尽力就好。但这个话是说给就真的神经很紧绷的妈妈们听的，那种就是“儿孙自有儿孙福”的这类人，你拿我这个话做借口的话那是不合适的。说到底我们尽力了以后就放松一些，放轻松，做好我们自己就好了。
