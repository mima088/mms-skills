# 米妈内容发布风控

发布前检查，目标是“能发，但不丢你的风格”。

## 检查项
1. 医疗/疾病/用药类敏感表述；
2. 绝对化承诺（保证有效、所有孩子都适用、万能）；
3. 焦虑贩卖/恐吓式表达；
4. 平台违禁词、导流红线（微信、加好友、私聊等）；
5. 隐私信息（真名、学校、可识别细节）。

## 输出
```
📋 发布风控报告
- [位置] [原句] → 风险等级 🔴🟡🟢 → 最小改动：「……」（保留原意和风格）
结论：可发 / 改后发 / 不建议发
```
原则：不把你的强观点磨平，只处理“会被平台误伤/引发实质风险”的点。
