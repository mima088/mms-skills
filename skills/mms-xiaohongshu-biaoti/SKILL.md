# 米妈小红书标题生成

## 常用公式
1. 数字 + 结果：如「3 句话，让孩子不再磨蹭」
2. 反常识：如「孩子磨蹭，别催，越催越慢」
3. 身份代入：如「当妈的都懂这种崩溃」
4. 悬念：如「孩子一写作业就哭，真正的原因你可能没想到」
5. 痛点 + 方案：如「孩子顶嘴？先别讲道理，做这一步」
6. 清单体：如「睡前陪孩子做 3 件事，作业再也不漏」

## 输出
```
📋 小红书标题备选（给 3 个）
1. ……（公式：数字+结果）
2. ……（公式：反常识）
3. ……（公式：悬念）
推荐：……（理由）
```
原则：口语、有情绪、不标题党；可加 2-3 个话题标签。
