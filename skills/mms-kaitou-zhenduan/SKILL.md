# 米妈口播文案开头诊断器

检查开头，并给出“贴着养育哲学、不指责家长”的改法。

## 六条检查

1. **拔高了吗**：开头是不是落在一个具体事件/具体年龄上？覆盖的人够不够多？
2. **反常识了吗**：有没有“我一直这么做，难道错了”的认知冲突？
3. **逻辑一致吗**：开头的结论，是不是正文那个“我以为 A，其实是 B”的核心转折？（不是就扣分）
4. **进故事快吗**：前 3 句是否进入故事？有没有空洞铺垫？
5. **句式可换吗**：反问式 / 直给式 / 反常细节式，能不能换着用，避免每篇一个模子？
6. **钩子类型**：这个开头属于 13 种钩子里的哪一种？还能叠加/换成哪 1-2 种？

## 13 种钩子库（给开头定位 + 换钩子）

1. 不稳定情绪登场（最重要最有效）— 高情绪开场：表情/突发状况/强冲突/快剪
2. 完形心理 — 并置陌生事物，让人本能想补齐关系
3. 与我有关 — 点名人群 /「没有男朋友的请划走」/ 痛点包装
4. 否定性力量 — 重大盲区 / 常识颠覆 / 撕开认知缺口
5. 社会身份敏感（慎用）— 站队 / 挑衅 / 自我贬低换优越感
6. 动物性欲望 — 食欲 / 解压 / 危险预警 / 闪闪发光
7. 围观与热闹 — 人多、场面热
8. 窥探 — 自我暴露 / 内幕揭秘 / 偷拍视角
9. 反常（反差）— 不可能的任务 / 陌生人物关系 / 独特情境
10. 特殊消息 — 独家 / 紧急预警 / 热议话题 / 新名词
11. 强节奏 — 密集短句、押韵、卡点
12. 人间美好（最基本）— 宁静、治愈、正向结果
13. 新奇有趣（可遇不可求）

换钩子原则：先判定当前钩子类型，再给「叠加/替换 1-2 个」的建议，并说明为什么更钩；换钩子要和正文核心转折一致，不是越多越好。

## 输出格式

```
📋 开头诊断报告

原文开头：「……」

逐条：
1. 拔高：✅ / ❌（说明覆盖人群够不够广）
2. 反常识：✅ / ❌
3. 逻辑一致：✅ / ❌（与正文核心转折是否吻合）
4. 进故事：✅ / ❌（前3句是否进故事）
5. 句式：当前是哪种起法，还能怎么换
6. 钩子类型：当前是第X种（……），可叠加/换成第Y种（……）

结论：合格 / 需要改

改法建议（给 2-3 个，可直接用）：
- 改法一：「……」
- 改法二：「……」
- 改法三：「……」
```

## 原则
1. 不指责创作者，说“这里可以更宽/更钩”，不说“你写错了”。
2. 每个改法都要能直接念出来，口语化。
3. 改法要贴着“活人感 + 情绪翻译 + 别指责家长”这条线。
4. 「社会身份敏感」钩子慎用，能不用就不用。
