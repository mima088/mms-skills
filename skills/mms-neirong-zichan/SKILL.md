# 内容资产管理（通用版）

把零散内容，变成可持续复用、可重组、可直接写稿的资产。

## 六类内容单元（全中文）

| 单元 | 是什么 |
|---|---|
| 问题 | 你的受众常问的困惑 |
| 概念 | 你自己的独家概念（你的方法论术语） |
| 观点 | 你的判断，能直接写进内容的一句话 |
| 案例 | 脱敏后的客户/学员案例 |
| 方案 | 可落地的方法步骤 |
| 人设事实 | 你本人/你的真实故事 |

## 核心能力

1. **拆单元**：把文稿拆成最小可复用单元，每个单元标注「能支撑什么主题 + 来源」。
2. **建工程**：标准骨架——规则层 / 单元库 / 主题地图 / 装配 / 处理状态。
3. **关系地图 + 主题地图**：单元怎么关联（回应/解释/证明/冲突），按主题聚类（用双链把单元串成图谱）。
4. **范文库**：范文 + 风格卡，**不提炼统一规则**（范文是活样本，逐篇标「一眼风格 + 适合写什么」）。
5. **人设事实库**：人设档案（静态事实）+ 事实清单（真实故事）+ 主题地图 + 提取规范。
6. **提取规范**：新内容自动拆——「事实」进人设事实库，「观点/方法」进单元库。

## 三类素材严格区分

- **人设事实** = 你本人/你的真实故事（禁止编造，禁止把客户案例混进来）。
- **内容单元** = 观点/方法/概念（专业弹药）。
- **案例** = 脱敏后的客户/学员案例（去真名、去可识别细节）。

## 工作模式

- **样本模式**：先抽少量样本拆单元，验证结构是否可维护。
- **批量模式**：结构稳定后，按批次推进，批后复盘口径是否漂移。

## 提取规范（新内容入库）

收到新内容时，按顺序拆：
1. 扫「你真实发生的故事」→ 提取成人设事实单元；
2. 扫「你的判断/方法/概念」→ 提取成内容单元；
3. 客户/学员案例 → 脱敏后入案例单元；
4. 更新主题地图与关系；
5. 新范文 → 存范文库 + 补风格卡。
