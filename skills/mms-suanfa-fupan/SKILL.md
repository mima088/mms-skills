# 米妈算法与数据复盘

2026 年起，老的数据判断经验大部分作废。按新算法判，不按旧经验拍脑袋。

## 2026 新算法核心变化
- 从标签匹配 → AI 行为预测（猜你喜欢）
- 考核周期从 24 小时 → 7 天长效赛马（收藏/复访/评论仍可二次三次推流）
- 内容裁判机制：优先推给领域专业用户，专业用户互动权重更高
- 指标权重（从高到低）：收藏率 > 复访率 > 铁粉互动 > 5秒完播 > 整体完播 > 评论 > 点赞 > 转发

## 流量池晋级（六阶漏斗）
种子池(300-500) 合规性 → 兴趣池(500-5000) 匹配度/互动 → 价值池 完播率/完播时长 → 扩量池 多维转化 → 高热池(200万级) 舆情 → 超级池(千万级)

## 视频权重公式
综合得分 = 0.35×VPS(内容价值) + 0.25×ENG(互动) + 0.2×RET(留存回访) + 0.15×TAG(标签精准) + 0.05×ACCT(账号基础)
- 80% 精力投入 VPS + ENG，其余达标即可
- 合格线参考：有效完播率≥38%、互动率≥12%、标签重度≥65%

## 先看的核心指标（新手只看这个）
- 5秒完播率（抖音）：<30% 说明开头不钩；流量话题 + 关键词可到 40%+
- 提 5秒完播三招：反常识开头 + 流量话题关键词 + 移动画面（米妈实测可到 50% 左右）；特殊场景（游泳馆/下雪/飞机）可更高
- 长视频（5分钟+）：发布后 24 小时数据只做初步判断，别盯数据

## 输出格式

```
📊 数据复盘报告

输入数据：播放 / 5秒完播 / 整体完播 / 收藏 / 复访 / 评论 / 点赞 / 转发

当前流量池判断：卡在……（第X级）
核心短板：……（对应哪项权重，缺多少）
最小优化动作：
1. ……
2. ……
（给可执行动作，不泛泛而谈）
```

## 原则
1. 先给判断（卡在哪、差在哪），再给动作。
2. 不制造数据焦虑：发完即扔、长推流机制、别盯实时数据。
3. 改动最小化：只动最影响当前晋级的那 1-2 项。
