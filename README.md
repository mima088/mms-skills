# MMS — Open-Source AI Skills for Short-Video Storytelling

> 米妈（MMS）口播技能包 · 开源版
> A toolkit of 19 AI Skills that take a real story from idea → script → diagnosis → title → publish → review.

**Core principle: real, alive, and never lecture your audience.**
**核心调性：真实、有活人感、别指责人。**

---

## What this is

19 installable Skills covering the full chain of short-video (口播) creation — for parenting, career, emotion, knowledge-sharing, or any experience-based content.

## Recommended Flow

1. **Idea** → `mms-linggan-bushou` or `mms-wubu-sop`
2. **Script** → `mms-yuanchuang-writer` (or `mms-fanwen-xiezuo` / `mms-nixi-shiyan`)
3. **Polish** → `mms-kaitou-zhenduan` → `mms-koubo-tijian` → `mms-gongming-zhenduan`
4. **Title** → built-in title trio, or `mms-xiaohongshu-biaoti`
5. **Publish** → `mms-fabu-fengkong`
6. **Review** → `mms-baokuan-chaijie` + `mms-neirong-zichan`

## Tiers（分层）

| Tier | Content |
|---|---|
| **Free / Open Source** | The 19 skills above — methods & tools only, no data |
| **Paid (199 community)** | Course knowledge base + Q&A skill (`mms-zimeiti-qa`) + community guidance |
| **Offline course only** | Narrative aesthetics, monetization, filming, group review, full internal edition |

> 免费开源版只提供「方法和工具」，不提供原文数据、案例库、知识库。用你自己的真实素材即可跑通。
